---

## 🏗️ Data Architecture

This project follows the **Medallion Architecture**, commonly used in modern data platforms.

### 🥉 Bronze Layer – Raw Data
- Stores raw data exactly as received  
- Data ingested from **ERP and CRM CSV files**  
- No transformations applied  

### 🥈 Silver Layer – Cleaned Data
- Data cleansing and standardization  
- Handling missing values and inconsistencies  
- Preparing data for analytics  

### 🥇 Gold Layer – Business-Ready Data
- Data modeled into a **star schema**
- Fact and dimension tables  
- Optimized for analytical queries and reporting  

All architectures, flows, and models are documented using **Draw.io**.
